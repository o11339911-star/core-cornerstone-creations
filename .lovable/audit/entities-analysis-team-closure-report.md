# تقرير إغلاق: الكيانات، تحليل الملفات، الصكوك والرخص، فريق العمل

## 1. تحليل الملفات (تحليل محلي بالكامل)
- `src/lib/analysis/extract.ts`: استخراج نص PDF عبر `pdfjs-dist` (worker مُحزَّم، بلا CDN)، تصنيف واستخراج حقول بقواعد عربية/إنجليزية (رقم، جهة الإصدار، تاريخ الإصدار/الانتهاء، المالك، المساحة، رقم المخطط، رقم القطعة، المدينة، الحي، الاستعمال، القيود، المكتب)، تطبيع كل الأرقام إلى اللاتينية.
- **التحليل الضوئي (OCR): معطّل بصدق** (`ocrAvailable = false`). لا يمكن تحزين بيانات تدريب عربية محليًا دون جلب خارجي، فتُعرض رسالة صريحة وتُتاح التعبئة اليدوية. لا يُرسل أي ملف إلى أي جهة خارجية.
- `src/lib/analysis.functions.ts`: `recordAnalysis` / `confirmAnalysis` / `rejectAnalysis` / `abortUpload` / `getAnalysis` / `listPropertyAnalyses` فوق الدوال المؤمَّنة في القاعدة.
- `src/components/documents/DocumentAnalyzer.tsx` + `src/routes/_authenticated/documents.analyze.tsx`: كشف التكرار بـSHA-256 **قبل** إنشاء أي سجل، ثم الاستخراج، ثم شاشة مراجعة قابلة للتحرير تعرض درجة الثقة والتعارضات، ثم الرفع والربط، ثم `review_required`. **لا يُطبَّق شيء على العقار قبل «اعتماد البيانات»**، وأي فشل رفع يستدعي `abort_document_upload`.

## 2. الصكوك والرخص
- رقم الصك/الرخصة صار **إلزاميًا** عند إنشاء سجل جديد (`DEED_NUMBER_REQUIRED` / `LICENSE_NUMBER_REQUIRED`).
- تحديث رأس الصك/الرخصة مقيّد بـ`property_id` كذلك، فلا يمكن استهداف سجل عقار آخر.
- فتح الملفات صار عبر `getDocumentDownloadUrl({ versionId })` مع رجوع للمسار القديم للسجلات القديمة فقط.
- نافذتا الإصدار تدعمان رفع ملف اختياري بمسار كامل (إنشاء مستند + حجز نسخة + رفع + ربط + إلغاء عند الفشل) وزر «تحليل الملف».

## 3. فريق العمل والإسنادات
- كل الإسنادات تمر عبر `create_project_assignment` / `update_project_assignment` (لا كتابة مباشرة)، مع `entity_id` إلزامي ورفض غير المنتمي للأطراف (`NOT_ASSIGNABLE`).
- إخفاء أدوات الإدارة كليًا عند غياب صلاحية `projects/update`، وإنهاء الإسناد بتاريخ الخادم.
- فريق الكيان: التحقق من `members.manage_members` أولًا؛ العضو العادي يرى القائمة فقط بلا بريد/جوال وبلا استعلامات فاشلة.
- حماية آخر مالك عبر تريغر ذرّي مع رسالة عربية واضحة.

## 4. الكيانات
- معالج الإنشاء صار بخطوات منطقية تنتهي بخطوة **مراجعة** للقراءة فقط مع الرجوع لأي خطوة.
- إخفاء المعرفات الرسمية (الرقم الموحد، السجل التجاري، الرقم الضريبي، البريد، الجوال) خادميًا لغير المخوّلين مع إبقاء آخر أربعة محارف.
- روابط عاملة: فريق العمل، المستندات (مفلترة بالكيان)، الملف العام، إضافة الكيان من قائمة الحساب في الشريط العلوي.

## 5. المشاريع
- لا يظهر أي UUID للمستخدم؛ الاسم بدلًا منه.
- قائمة العقارات تُطلب فقط لكيان من نوع «مطوّر».
- فشل ربط العقار بعد إنشاء المشروع لم يعد يُخفى: تحذير مرئي وإعادة محاولة.

## 6. التحقق
- `bunx tsgo --noEmit`: نظيف.
- `bun run build`: ناجح.
- مسح Unicode لكامل `src/`: **صفر أرقام عربية/فارسية** (U+0660–0669، U+06F0–06F9).
