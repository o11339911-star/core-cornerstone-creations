# المرحلة 0 — الاستلام والتدقيق وتثبيت خط الأساس (ركيز)

## ما تم التحقق منه فعليًا الآن (قراءة فقط)

- **الإطار**: TanStack Start v1 + React 19 + Vite + Tailwind v4 (`package.json`).
- **المسارات الموجودة**: `src/routes/__root.tsx` و `src/routes/index.tsx` فقط. لا يوجد أي مسار آخر ولا مجلد `api/` ولا `_authenticated/`.
- **المكونات**: `src/components/ui/*` (مكتبة shadcn الافتراضية كاملة) — لا توجد أي مكونات خاصة بركيز خارج صفحة الهبوط.
- **الأصول**: `src/assets/rakeez-hero.jpg` فقط.
- **الترجمة**: لا يوجد نظام i18n ولا ملفات ترجمة؛ النصوص العربية مكتوبة مباشرة داخل الصفحة.
- **Supabase / Lovable Cloud**: **غير مفعّل**. لا يوجد مجلد `supabase/`، ولا `src/integrations/supabase/*`، ولا أي migration. بالتالي: لا جداول، لا سياسات RLS، لا دوال، لا triggers، لا views، لا buckets.
- **Git**: المستودع النشط هو مستودع Lovable الداخلي (origin + secondary). الفرع الافتراضي `main`، مع فروع تحرير مؤقتة `edit/*`. **لا يوجد أي remote يشير إلى `1127410650/11`** — أي ربط GitHub الخارجي غير مُثبت في هذه النسخة.
- **آخر لقطة مستقرة**: الالتزام `5f84346` على `main`.

## الفجوات مقابل "منصة ركيز"

المشروع حاليًا صفحة تعريفية ساكنة واحدة. كل ما يخص المنصة (مصادقة، أدوار، قاعدة بيانات، لوحات تحكم، طلبات، مدفوعات، إشعارات، تعدد اللغات، وصولية) **غائب بالكامل**. لا يوجد تعارض تقني — فقط غياب.
