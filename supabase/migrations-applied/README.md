# هجرات جاهزة للتطبيق (غير مطبَّقة)

هذه الملفات **لم تُطبَّق** على قاعدة البيانات. صلاحية إدارة Supabase حاليًا مرفوضة
(`SUPABASE_FORBIDDEN`)، وأداة الهجرات المعتمدة هي الوسيلة الوحيدة المسموح بها للتطبيق.

بعد إعادة مصادقة Supabase تُطبَّق بالترتيب التالي عبر أداة الهجرات المعتمدة:

1. `01_platform_references.sql` — جدول المراجع الموحّدة `Rakiz` (أرقام 0-9 فقط، عشوائية وفريدة) + مولّد آمن.
2. `02_appointments_reference_lifecycle.sql` — مرجع للموعد، حالة «مؤجل»، حجز باسم حساب شخصي، تحقق آمن بالمرجع (QR).
3. `03_network_contacts.sql` — وحدة «شبكة التواصل»: جهات الاتصال الخاصة، طلبات التواصل، الارتباطات وأذونات المشاركة.

الكود في `src/lib/network.functions.ts` و`src/lib/appointments.functions.ts` يتعامل مع
غياب هذه الكائنات بهدوء: يعرض حالة منتج طبيعية بدل رسالة تقنية، ويعمل تلقائيًا فور التطبيق.
